# HIME STUDIO — локальные фотографии дизайнов

Пока каталог использует изображения, хранящиеся непосредственно в репозитории. Позже эти же записи можно будет перенести в Supabase Storage.

## Как добавлять фотографии

1. Добавляйте только собственные фотографии или изображения, на использование которых у проекта есть разрешение.
2. Используйте JPG, PNG или WebP; для мобильного каталога предпочтителен WebP/JPG.
3. Делайте вертикальные кадры в едином стиле (ориентир 4:5), без водяных знаков и чужих логотипов.
4. Имена файлов — латиницей, в нижнем регистре, без пробелов. Например: `burgundy-almond-001.webp`.

## Категории

Создавайте подпапки по мере наполнения:

- `bright/` — яркие
- `light/` — светлые
- `dark/` — тёмные
- `nude/` — нюдовые
- `pastel/` — пастельные
- `french/` — френч
- `matte/` — матовые
- `glossy/` — глянцевые
- `glitter/` — блёстки

Длина и форма ногтей, стиль и покрытие должны быть указаны в метаданных карточки каталога, а не только в имени файла.

## Ограничения Git

Не добавляйте огромные оригиналы и видео в Git. Оптимизируйте фотографии перед загрузкой; для больших коллекций и пользовательских загрузок перейдём на Supabase Storage. Не коммитьте секретные ключи.
